# Команда проекта «Портал образовательных материалов»

> ФГБОУ ВО «РГАУ–МСХА имени К.А. Тимирязева»

## О проекте

Веб-портал для публикации и чтения образовательных материалов, ориентированный на студентов бакалавриата. Читатели просматривают статьи, делают закладки и цитаты, скачивают материалы для офлайн-чтения; авторы публикуют материалы; администраторы управляют пользователями и контентом.

**Срок MVP:** 4 месяца (до конца семестра).
**Согласующий:** Храмов Дмитрий Эдуардович — согласовал все варианты использования.

## Пересечения между участниками

- Удаление материала (6.2, Хоптяная) влияет на закладки (4.2, Гринь): закладки других пользователей помечаются как недоступные.
- Роли (3, Филимонова) определяют, кто видит функции публикации (6.1) и административную панель.
- Авторизация (2, Лушникова) создаёт сессию и роль, от которых зависят все остальные сценарии.
- Просмотр материалов (5, Филимонова) — точка входа для добавления в закладки (4.1).
