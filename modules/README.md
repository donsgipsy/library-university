# Отдельно разрабатываемые модули

| Модуль | Разработчик | Что реализовано |
| --- | --- | --- |
| [Закладки](bookmarks/README.md) | Гринь Вероника | Добавление, просмотр и удаление закладок пользователя. Закладки хранятся в SQLite. Модуль проверяет идентификаторы, предотвращает дубликаты и покрыт автоматическими тестами. |
| [Каталог материалов](material-catalog/README.md) | Филимонова Евгения | Список опубликованных материалов, поиск по ключевым словам, фильтрация по категории, автору и дате, просмотр полного материала. Добавлены функция получения краткой информации для закладок, проверка данных из JSON и автоматические тесты. |
| [Публикация материалов](material-publication/README.md) | Хоптяная Мария | Создание черновиков, прикрепление файлов, проверка обязательных полей и ограничений на вложения. При создании материал получает уникальный идентификатор, при публикации — статус `published` и дату публикации. |
| [Регистрация пользователей](user-registration/README.md) | Лушникова Анна | Регистрация читателя по номеру телефона с одноразовым кодом и выдачей токена сессии. Реализованы проверка номера, срок действия кода, блокировка после повторных ошибок и автоматические тесты. В консольной демонстрации код выводится на экран, данные хранятся в памяти. |
