# Регистрация пользователя по номеру телефона

## Разработчик

Лушникова Анна.

## Назначение и связь с материалами

Модуль реализует регистрацию читателя после подтверждения номера: **ФТ-1 → UC-1 → диаграмма последовательности UC-1** ([описание и диаграмма](../../docs/md/lushnikova-report.md)). Это самостоятельный фрагмент портала; авторизация существующего пользователя (ФТ-2, UC-2) в него не входит.

## Интерфейс

- `RegistrationService(sms_gateway, clock=...)` принимает шлюз с методом `send(phone, code)` и необязательные часы. Шлюз сообщает об ошибке через `SmsError` или о недействительном номере через `InvalidPhoneError`.
- `request_code(phone)` принимает строку номера в международном формате `+` и 8–15 цифр, отправляет шестизначный код и сохраняет его на 5 минут.
- `confirm(phone, code)` принимает номер и строку из шести цифр. При успехе возвращает сессию с токеном и пользователем (`id`, `phone`, `role`). Создаётся учётная запись с ролью «Читатель», код удаляется. Ошибки сообщаются через `RegistrationError`.
- Проверяются формат и занятость номера, ошибка шлюза, неверный и просроченный код. После пяти неверных попыток ввод и повторная выдача кода блокируются на 15 минут.

## Запуск

Требуется Python 3.9 или новее, сторонние пакеты не нужны. Из корня репозитория:

```text
python modules/user-registration/registration.py
```

Введите, например, `+79991234567` и затем код, показанный демонстрационным шлюзом. Можно вводить неверные данные и запросить повторную отправку словом `новый`. Для выхода на запросе номера введите `exit`.

Проверка автоматических сценариев:

```text
python -m unittest discover -s modules/user-registration -p "test_*.py"
```

## Текущее состояние и ограничения

Код, пользователи, блокировки и сессии хранятся только в памяти процесса и исчезают после его завершения. Консольный шлюз выводит код на экран, реальную SMS не отправляет и не проверяет существование номера. Подключение настоящего шлюза, постоянного хранилища и интеграция с порталом потребуются на следующем этапе. Реализация предназначена для локальной демонстрации, не для промышленного развёртывания.
