# Модуль публикации материалов (material-publication)

## Разработчик
Хоптяная Мария

## Назначение
Модуль отвечает за создание, валидацию и публикацию учебных материалов, а также за прикрепление к ним файлов. Он позволяет формировать черновики, проверять обязательные поля и ограничения на файлы, а также публиковать материалы с присвоением уникального идентификатора и даты.

## Связанные требования
- ФТ-10 — публикация материалов
- ФТ-11 — прикрепление файлов

## Связанный вариант использования
- UC-6.1 — публикация материала

## Входные данные
Модуль принимает следующие данные:
- **Название материала** (обязательное)
- **Содержание материала** (обязательное)
- **Описание материала** (необязательное)
- **Категория материала** (обязательное)
- **Список путей к файлам** (необязательное)

## Результат
- Успешно созданный черновик материала с присвоенным уникальным ID и статусом `draft`.
- Опубликованный материал со статусом `published` и зафиксированной датой публикации.
- В случае некорректных данных — выброс исключения `ValidationError` с описанием ошибки.

## Запуск
Для запуска консольного интерфейса и проверки работы модуля необходимо перейти в папку модуля и выполнить команду:

```bash
cd modules/material-publication
python3 main.py
