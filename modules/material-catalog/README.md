# Модуль просмотра материалов (material-catalog)

## Разработчик
Филимонова Евгения

## Назначение
Каталог опубликованных материалов: вывод списка, поиск по ключевым словам,
фильтрация по категории, автору и дате, просмотр полного материала.
Черновики (status != published) в каталоге не показываются.

## Связанные требования
ФТ-3 — просмотр материалов.

## Связанный вариант использования
UC-5 — просмотр материалов.

## Структура
```
modules/material-catalog/
  __init__.py        # публичный интерфейс пакета
  catalog.py         # логика модуля (функции)
  main.py            # консольное меню и командная строка
  materials.json     # тестовые данные
  tests/test_catalog.py
  README.md
```
Каталог назван `material-catalog` (с подчёркиванием), чтобы модуль можно было
импортировать стандартными средствами Python.
Подход функциональный: небольшой самостоятельный модуль без классов репозитория,
сервиса и модели.

## Входные данные
- `query` — ключевые слова (необязательно; должны встретиться ВСЕ слова);
- `category` — точное название категории (необязательно);
- `author` — часть ФИО автора (необязательно);
- `date_from`, `date_to` — границы даты публикации, формат ГГГГ-ММ-ДД, включительно (необязательно);
- `id` — целый идентификатор материала (для просмотра).

## Результат
- `get_catalog(...)` — список материалов (id, название, автор, дата, категория, описание), новые первыми;
- `get_material(id)` — полный материал по id;
- `get_material_summary(id)` — название, автор и описание по id (для других модулей, например закладок).

Ошибки: `ValidationError` (неверная дата, дата начала позже даты окончания, нецелый id),
`MaterialNotFound` (материал не найден или не опубликован),
`DataFileError` (файл данных отсутствует, повреждён или содержит некорректные значения).

## Формат данных (materials.json)
Список объектов с полями: `id` (целое, уникальное), `title`, `author`, `category`
(непустые строки), `description`, `content` (строки), `published_at` (ГГГГ-ММ-ДД),
`status` (`published` или `draft`). Типы и значения полей проверяются при загрузке.

## Запуск
Требуется Python 3.12, сторонние библиотеки не нужны.

```bash
cd modules/material-catalog
python main.py                                   # интерактивное меню
python main.py list                              # все опубликованные
python main.py list --query данных               # поиск
python main.py list --category Аналитика --author Филимонова --from 2026-09-01 --to 2026-10-31
python main.py show 3                            # полный материал
```

Использование из другого модуля (из корня репозитория):
```python
from modules.material-catalog import get_material_summary
get_material_summary(3)   # {'id': 3, 'title': ..., 'author': ..., 'description': ...}
```

## Текущее состояние
Реализовано: список, поиск, фильтры, просмотр полного материала, получение краткой
информации по id для закладок, проверка типов и значений полей JSON, автоматические тесты.
Источник данных — файл `materials.json` (учебные данные).
Ограничения: нет подключения к БД и фактической интеграции с модулем закладок
(подготовлена функция `get_material_summary`); управление ролями (UC-3/ФТ-19) вынесено
в отдельный модуль; поиск — по подстроке без морфологии; пагинации нет.
