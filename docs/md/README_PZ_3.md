## Краткое содержание вариантов

**1. Регистрация по номеру телефона.** Ввод номера в международном формате, проверка формата и уникальности, генерация 6-значного кода (действует 5 минут), отправка через SMS-шлюз, подтверждение кода, создание учётной записи с ролью «Читатель». Ошибки: неверный формат, номер занят, сбой шлюза, неверный код (5 попыток, затем блокировка на 15 минут), истёкший код, несуществующий номер.

**2. Авторизация.** Два способа: по SMS-коду или по номеру и паролю. Проверяются статус учётной записи, срок действия пароля (180 дней), создаётся сессия, событие пишется в журнал. Отдельно обработаны: учётная запись не найдена, заблокирована, неверный пароль, истёкший пароль (принудительная смена).

**3. Управление ролями.** Суперпользователь (единственный) назначает роли «Читатель», «Автор», «Администратор»; Администратор — только «Читатель» и «Автор». Запрещены смена собственной роли и повторное назначение той же роли; все изменения пишутся в журнал.

**4.1–4.3. Закладки.** Добавление (без дублей), просмотр списка (новые сверху; удалённые материалы помечаются «недоступен»), удаление с подтверждением.

**5. Просмотр материалов.** Список карточек, фильтры по категории, дате и автору, поиск по названию, описанию и содержимому, открытие материала; особая обработка файловых версий (PDF, DOCX и др.), пустой выдачи и удалённых материалов.

**6.1. Публикация материала.** Форма (название, содержание, краткое описание), прикрепление файлов (до 50 МБ, разрешённые форматы), проверка обязательных полей, публикация или сохранение черновика, удаление файла до публикации.

**6.2. Удаление материала.** Мягкое удаление (статус «Удалён»), подтверждение, проверка авторства, пометка закладок других пользователей как недоступных, запись в журнал; попытка удалить чужой материал блокируется и фиксируется в журнале безопасности.
