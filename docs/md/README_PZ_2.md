# ПЗ-2. Функциональные и нефункциональные требования

> Файл: `PZ_2.docx`

## Назначение системы

Портал для публикации образовательных материалов преимущественно для студентов бакалавриата.

## 1. Роли в системе

| Роль | Как появляется | Основные права | Ограничения |
|---|---|---|---|
| **Читатель** | Автоматически после подтверждения номера по SMS | Просмотр материалов, закладки, цитаты, скачивание HTML и файлов, техподдержка, уведомления | Не публикует, не редактирует чужое, не меняет свою роль, нет доступа к админ-функциям |
| **Автор** | Назначается администратором из зарегистрированных пользователей | Всё, что у Читателя, плюс создание, редактирование и удаление своих материалов, загрузка файлов, статистика просмотров | Не трогает чужие материалы, нет доступа к логам, не управляет ролями |
| **Администратор** | Создаётся при развёртывании или назначается действующим администратором | Полный доступ: пользователи, роли, материалы, логи, настройки, политики безопасности, рассылки, тестовый функционал | Отсутствуют |

## 2. Функциональные требования

### Читатель

| № | Требование | Ключевые параметры |
|---|---|---|
| ФТ-1 | Регистрация по номеру телефона | SMS-код из 6 цифр, срок действия 5 минут |
| ФТ-2 | Авторизация | По SMS-коду или по логину и паролю |
| ФТ-3 | Просмотр материалов | Список, фильтры (категория, дата, автор), поиск по ключевым словам |
| ФТ-4 | Закладки | Добавление, список с датой, удаление, сортировка по дате и алфавиту |
| ФТ-5 | Сохранение цитат | Привязка к материалу и автору, комментарий к цитате |
| ФТ-6 | Скачивание статей в HTML | Для офлайн-чтения, список скачанных статей |
| ФТ-7 | Обращение в техподдержку | Статусы: новое, в работе, решено, отклонено; вложения |
| ФТ-8 | Персональные уведомления | Срок пароля, статус обращений, смена роли, системные рассылки |
| ФТ-9 | Личный профиль | Данные, смена пароля, настройки уведомлений, статистика активности |

### Автор

| № | Требование | Ключевые параметры |
|---|---|---|
| ФТ-10 | Публикация материалов | Визуальный редактор, черновики, обязательные поля «Название» и «Содержание» |
| ФТ-11 | Загрузка и прикрепление файлов | До 50 МБ; PDF, DOCX, PPTX, XLSX, PNG, JPG, ZIP |
| ФТ-12 | Редактирование своих материалов | Дата последнего обновления; история изменений (по желанию) |
| ФТ-13 | Удаление своих материалов | Подтверждение; файлы удаляются вместе с материалом |
| ФТ-14 | Статистика публикаций | Просмотры только своих материалов |
| ФТ-15 | Управление прикреплёнными файлами | Добавление, замена, удаление, порядок |

### Администратор

| № | Требование | Ключевые параметры |
|---|---|---|
| ФТ-16 | Полное управление материалами | Любые материалы; модерация перед публикацией (опционально) |
| ФТ-17 | Управление файлами | Все файлы, контроль объёма хранилища |
| ФТ-18 | Управление пользователями | Поиск, создание, блокировка, удаление |
| ФТ-19 | Управление ролями | Назначение и понижение, журнал изменений |
| ФТ-20 | Настройка параметров системы | Название, главная страница, категории, политики модерации |
| ФТ-21 | Политика безопасности | Длина и сложность пароля, срок 180 дней, активные сессии, принудительный сброс |
| ФТ-22 | Мониторинг активности | Действия пользователей, подозрительные входы, графики |
| ФТ-23 | Системные журналы | Ошибки, действия, входы, события; поиск и экспорт |
| ФТ-24 | Массовая рассылка уведомлений | Целевая группа, отправка по расписанию, история |
| ФТ-25 | Обращения в техподдержку | Статусы, ответы, назначение ответственного, закрытие с причиной |
| ФТ-26 | Закрытый функционал для тестирования | Режимы «продакшн / тестирование», скрытые разделы |

## 3. Нефункциональные требования

### Общие
- **Адаптивность:** корректная работа на десктопах, ноутбуках, планшетах и смартфонах; на мобильных без горизонтальной прокрутки.
- **Кросс-браузерность:** актуальные Chrome, Firefox, Edge, Safari; ОС Windows, macOS, Linux, iOS, Android.
- **Срок действия пароля:** не более 180 дней; после истечения работа невозможна без смены пароля.
- **Предупреждение об истечении пароля:** в личном кабинете показывается число оставшихся дней и ссылка на смену пароля.

### Для Читателя
Регистрация только после подтверждения SMS; нельзя публиковать и редактировать чужие материалы; нельзя менять свою роль; нет доступа к административной панели.

### Для Автора
Создание материалов и загрузка файлов; редактирование и удаление только своих публикаций; статистика только своих материалов; чужой контент недоступен для изменения.

### Для Администратора
Автоматическое создание первого администратора при развёртывании (либо назначение другим администратором); полный набор прав; управление пользователями, контентом, журналами и настройками.
