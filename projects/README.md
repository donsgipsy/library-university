# Программная часть продукта

Этот раздел содержит исходный код и документацию по реализации приложения.
- src/ – исходный код приложения (пока содержит .gitkeep, наполняется по мере разработки).
- docs/ – документация по реализации, настройки и инструкции по запуску.

*Текущий этап:* Структура создана, ожидается наполнение кодом в следующих итерациях.
